# C_Sharp_LINQ_ProductFilter

## C#_LINQ_ProductFilter

### Задание «Контрольная точка №35 — введение в LINQ, базовые запросы»

Вариант 1. Фильтр товаров
1. `List<Product>` (название, цена, категория) минимум из 6 элементов.
2. Цепочка `Where` (цена выше определённого порога) $\rightarrow$ `OrderBy` (по цене) $\rightarrow$ `Select` (проекция в строку с названием и ценой).
3. Выведите результат цепочки через `foreach`.
4. Продемонстрируйте `Count` (сколько товаров дороже порога) и `Any` (есть ли товар дороже другого порога).
5. Измените порог в `Where` и покажите, что результат цепочки изменился соответственно.
